# Assets and provenance

No third-party artwork, sky catalog, remote font, or model asset is bundled. The dashboard uses CSS, text and Unicode symbols. Future asset manifests must record source, license, content hash, media type and byte size, with an explicit review step before publication.

Untrusted media uploads belong in an approved isolated Storage prefix, not this repository or executable script paths. Do not embed private profile data, seal keys, local environment files or user notes in static export assets.
