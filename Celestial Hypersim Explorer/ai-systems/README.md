# Future AI systems boundary

No model API, embedding provider, prompt execution or generated scene is installed. AI-assisted organization, semantic search and world generation are future, optional adapters.

Inputs must be explicitly selected, access-filtered non-secret content. Outputs are untrusted structured proposals with source attribution and schema/size validation. Require user review before persistence or publication. Never execute generated code, grant roles, issue seals, approve course completion or award Vis based on model output. Private notes, Ledger Seeds and Minor Tome keys are excluded by default.

Continuation gate: provider/data-retention approval, scoped credentials through secure settings, cost/rate limits, injection-resistant tool boundaries, provenance and safe deletion/export behavior.
